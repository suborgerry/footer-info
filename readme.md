# 📞 Footer Info

A simple WordPress plugin that lets you add and display contact information automatically in the footer of your website.

## 🔍 What does this plugin do?

- Adds a settings page under **Settings → Footer Info**
- Allows the site administrator to input:
  - 📞 Phone number
  - ✉️ Email address
  - 📍 Physical address
  - ⏰ Working hours
- Lets you choose which fields to display using checkboxes
- Automatically displays the selected contact info in the site footer
- Includes basic styling for nice appearance

---

## ⚙️ Installation

1. Download the plugin archive `footer-info.zip`.
2. Go to your WordPress admin panel.
3. Navigate to **Plugins → Add New**.
4. Click **Upload Plugin**, select the `footer-info.zip` file, and click **Install Now**.
5. After installation, click **Activate Plugin**.

---

## 🧾 How to use

1. Go to **Settings → Footer Info** in the WordPress dashboard.
2. Fill in the contact details:
   - Phone number (e.g., `+380991234567`)
   - Email (e.g., `example@email.com`)
   - Address (e.g., `123 Example St, Kyiv`)
   - Working hours (e.g., `Mon–Fri 09:00–18:00`)
3. Use the checkboxes to choose which fields should appear on the site
4. Click **Save Changes**
5. The selected info will automatically appear in the footer of your site

---

## 🧹 Uninstallation

If you delete the plugin, all saved settings will also be removed from your database to keep things clean.
